# 无障碍管理器 1.2.3

> 承接 1.2.2 的功能 + 架构收口版。**这一版主要给你们实测** —— 有一批改动此前只有静态验证、
> 没上过真机，所以末尾专门列了「请重点测什么」。

## 新功能

- **详情卡片改成悬浮卡片**（此前是弹窗式抽屉）
  - 手机：仍贴底、只圆顶部大角（观感不变），但不再压在系统窗口上
  - 平板（内容宽 ≥600dp）：改为**居中悬浮卡片**（28dp 圆角，宽 500dp 且不超过屏宽 60%）
  - 两种形态都带 32% 遮罩、点遮罩即可关闭
  - **旋转 / 窗口尺寸变化时卡片不再关闭**，会保留并恢复到同一个服务

- **应用图标的「素材复用」转场**：点卡片打开详情时，那个应用图标会从列表位置**飞到**详情头部
  （此前是整体淡入）。这是设计规范里定义的共享元素转场。
  ⚠️ 飞行期间列表里那个图标位会**短暂留空** —— 这是"素材复用"的正常语义，但观感是否可接受**要你判**。

## 修复

- **未授权横幅双重显示、且颜色语义相反**：同一状态此前同时渲染两处，一处把"未授权"当错误红底、
  另一处当状态中性底。已删除冗余的那处。
- **恢复失败提示从 3 处收成 2 处**：保留「列表行角标」（能定位到哪个服务）与「设置页汇总行」，
  删掉页级横幅（重复的全局提示）。

## 内部变化

- 业务层全部 Kotlin（仓库内 Java 文件清零）
- 保活链的「写入 + 镜像」协议收成单一实现（此前散在 5 处手写、镜像跨两个类）
- 「扫描已启用配置」「: 串切分」「周期取大单位」各归一到唯一实现（此前 3/4/2 份重复）
- 删除 2 个零调用的死方法
- **新增核心逻辑回归测试 16 个**（瞄准历史缺陷：子串误判致掉线不恢复、移除留垃圾段）

## ⚠️ 请重点测什么（这些此前只有静态验证）

1. **保活链**（最重要）：把某个无障碍服务关掉再开、或在系统设置里取消再勾选，
   看是否正常恢复、有没有出现"自己跟自己打架"式的反复启停。
2. **图标转场观感**：点卡片时图标的飞入效果；**尤其看飞行期间列表里那个图标位留空是否能接受**。
3. **平板悬浮卡片**：宽度 ≥600dp（或分屏）时卡片是否居中、圆角与宽度是否正常。
4. **旋转 / 分屏拖动**：卡片打开时旋转屏幕 —— 应该**不关闭**、仍显示同一个服务。
5. **设置页底部的版本号**应显示 **1.2.3**（此前是写死的 v9.0）。

## 已知遗留 / 未验证

- 上面 5 条**均未做真机回归**（本版就是为了测）。

- lint 在当前工具链下仍不可用，不作为验收依据。
