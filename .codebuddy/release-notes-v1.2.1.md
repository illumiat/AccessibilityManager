# 无障碍管理器 1.2.1（修复版）

> 在 1.2 基础上的**修复版**。本轮聚焦四类问题：保活链路的既有缺陷修复、动态取色的运行期切换、
> 无障碍语义修复、列表行高档位修正。未引入新功能；界面观感基本不变（设置页文本对齐、
> 部分列表行高度与图标圆角有可感知的修正）。

## 修复

- **保活镜像自触发隐患（代码层修复）**：重启调度读回系统设置值后，原来只在「读回非空」时才校准
  镜像值，会让镜像停在刚写入的值、与实际读回值不符，观察者可能把**自身写入**误判为外部改动。
  现改为读回后**无条件**校准镜像，消除自触发风险。
- **守护者卸载清理更稳妥**：卸载清理分支补 `cancelIfIdle`（两处同口径）；补偿分支补
  「应用是否已安装」校验，避免对已卸载应用执行无效操作。
- **动态取色运行期切换（修复）**：此前动态取色在应用进程级注册，导致运行期切到「跟随壁纸」
  不生效、切回命名主题回不去。现改为在 `MainActivity` 按当次持久化主题对**单个 Activity** 应用，
  使运行期切换不再依赖进程级注册。
- **无障碍语义修复**：列表区块标题补 `heading()` 语义；图标槽占位分支清空自身语义（占位文字不再进入语义树）；
  卡片锁定按钮的标签两种状态都提供、未启用时不再声明按钮角色；按压反馈补焦点/悬停描边。
- **列表行高档位修正**：列表项行高原来按单一上限推导，现改为同时依据标题与副标题的最大行数，
  副标题允许 3 行时档位正确生效。
- **设置页水平内缩统一**：此前组件侧与非组件侧内缩不一致（32dp / 16dp 错位），
  现收敛到唯一归属，设置页文本左边界统一在 16dp。
- **周期对话框校验收紧**：改为溢出前置判定，非法 `Long` 回绕不再能绕过输入校验。

## 内部变化

- 图标槽位图分支补形状裁剪（与占位分支同形状）。
- 主题偏好名与键统一走 `ThemePref` 访问器；夜间模式选择镜像进 `ui`。
- 设计系统清理：`AppTheme` 角色查询提取为 `ColorSchemeRoles`；删除未使用的 `showsWarning`
  与 `EffectTokens` 的 overlay 组；`SizeTokens.IconSmall` 18→20dp。
- 依赖收编：`work` / `shizuku` 纳入版本目录；删除零引用的 `coreKtx` / `window` / `lifecycle`。
- 清理死代码：删除死方法 `updateRestartSummary`、死串 `list_loading`；
  主题 / 对比度的面向用户文案移出设计系统库，改由 app 层 `labelRes()` + `strings.xml` 映射。
- 权限链 `PermissionHelper` 提取 `grantCommand(context, withExit)`，删除 `minSdk 24` 下不可达分支。

## 兼容

- 安装方式不变：release 构建 + debug keystore 签名，**可覆盖 1.2 安装，无需卸载**。
- 最低系统、授权方式、数据与配置沿用（与 1.2 一致）。

## 已知遗留 / 仍未验证

- 保活与补偿链路仍有未做真机回归的项：**灭屏 / 亮屏触发、伪关闭恢复、权限撤销告警、多服务并发**。
- 动态取色运行期切换的「方向 B」尚未验证：进程以「跟随壁纸」启动时切回命名主题，
  overlay 与 `setTheme` 的先后次序谁胜，尚未在真机确认。
- 评审提到的「三行策略文案是否溢出」未在真机量过。
- 详情卡外壳提取（`ServiceDetailScreen`）的外观等价未逐项比对。
- 动态取色「跟随壁纸」下**对比度档不生效**：这是已裁决的取舍（跟随系统动态取色不提供对比度入参），
  非待修缺陷。
- lint 在当前工具链（AGP 8.7.3 + compose）下仍不可用，不作为验收依据。
