# 无障碍管理器 MD3 重构版 1.1

## 新增

- **主页搜索栏**：输入即过滤服务（匹配名称 / 包名 / 标签，置顶顺序保留）；平板 360dp 限宽
- **顶栏重构**：应用名横幅字 + 告警横幅（未授权 / 恢复失败）+ 搜索栏一体化
- **实机截图**：README 展示手机与平板实际界面

## 修复

- **惰性调度**：定期重启周期任务仅在存在启用配置时注册，全部关闭自动取消——未使用该功能的用户恢复**零主动唤醒**（对齐 1.0 文案承诺）
- **网格阈值校准**：单卡最大宽 400→500dp，修复密度调整后的手机竖屏误入 2 列；进入时不再闪跳
- **置顶路径数据同步**：修复置顶后重复行 / 丢行（含 Inconsistency 崩溃风险）
- **详情卡开关闭包**：修改周期后不再被旧值静默回退
- **锁图标 M3 化**：矢量 Material Symbols（主题着色），尺寸调优，状态即时跟随
- **观察者注销泄漏**、**异常段越界崩溃**、**失败告警常驻误报**等多处稳定性修复

## 其他

- versionCode 单调递增（10），versionName 1.1
- 最低系统：Android 7.0
