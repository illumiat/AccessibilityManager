# 无障碍管理器 MD3 重构版 1.2

> 相对 1.1：界面**全面改用 Jetpack Compose 重写**（此前为 View + XML），
> 并按「MD3 骨架 × 苹果标尺」设计规范落了一整套设计系统。
> 这不是渐进改造，而是界面层的重制 —— 观感与手感都有明显变化。

## 新增

- **命名主题 4 个**：品牌 / 中性 / 单色 / 跟随壁纸（默认品牌）。
  此前只支持「跟随系统 / 浅色 / 深色」三态，无法切换配色风格。
- **对比度 4 档**：降低 / 默认 / 较高 / 最高。对高对比敏感、偏头痛、轻度视力障碍的用户可自行调节。
- 配色由**构建期算法生成**（24 套调色板 + 12 套主题样式），而非手写色值 —— 改源色即整体重算。

## 界面重绘

- **全部界面迁至 Jetpack Compose**（外壳 / 主页 / 设置 / 详情弹卡 / 对话框）。
- **设计系统落地**：形状、间距、尺寸、字阶、按压反馈、动效全部 token 化，
  不再有散落的硬编码取值（颜色一律走语义角色，不出现十六进制）。
- **主页卡片统一 88dp 等高**。此前卡片高度随内容在 64 / 84 / 108dp 之间波动，
  同一行内两个卡片都可能不等高，多列时尤其参差不齐。
- **应用图标垂直居中**：此前受卡片定高方式影响，图标中心比卡片中心偏上 12dp。
- **置顶标记重做**：此前是叠在应用图标右上角的文字标签，实测遮住图标约 1/4
  （标签 79×56px，而图标容器仅 140×140px）。现移至尾部状态区、
  与锁定按钮纵向排列，既不遮挡图标也不挤窄标题。
- **详情弹卡重绘**：卡片式信息分组 + 只读标签片 + 更清晰的重启周期区。
- **周期对话框重做**：单位改为分段按钮；非法输入时**字段就地报错**并禁用确认键。

## 修复

- **列表标题与描述不更新**：图标异步加载完成后，标题此前**永远停在服务类名**
  （看起来像包名，如 `.enhance.tb.MiuiEnhanceTService`），描述永远显示"该服务没有描述"。
  现随加载完成即时补全为应用名/服务名与真实描述。
- **搜索无结果误报**：此前搜不到时显示"未发现任何无障碍服务"——
  在装有服务的设备上会**误导用户以为设备没装服务**。
  现区分「搜索无结果」与「零服务」两种状态，前者回显查询词并给出"清空搜索"。
- **设置页开关视觉回弹**：拨动后开关会弹回原位，需退出重进才追上。现即时跟随。
- **相邻触控目标间距**：锁定按钮与开关间距 4dp → 8dp（规范要求相邻 ≥8dp）。
- **空态图标尺寸**：96dp → 56dp（规范要求 48–56dp），并补上此前缺失的"下一步"说明文字。

## 内部变化

- **业务层全部由 Java 转为 Kotlin**（保活服务 / 重启调度 / 配置持久化 / 图标缓存 / 权限链）。
  逐行保真转换、行为不变；锁身份、线程模型、镜像同步点均按原样保留。
- **发布包改用 release 构建**：性能改善明显 —— 同场景实测
  掉帧率 **11.33% → 0.35%**，帧时中位数 **18ms → 5ms**（此前 debug 构建的固有开销）。
- lint 在当前工具链（AGP 8.7.3 + compose 1.11）下不可用（AndroidX lint 检测器与 AGP 内置
  Kotlin 分析 API 二进制不兼容，任务直接崩溃），已记入待办，不再作为验收依据。

## 兼容

- **安装方式不变**：debug 签名，可直接覆盖 1.0 / 1.1 安装，无需卸载。
- 最低系统：**Android 7.0**（未变）
- 授权方式不变：ADB / root / Shizuku 授予 `WRITE_SECURE_SETTINGS`
- 数据与配置**完全沿用**（`restart` / `data` 两个 SharedPreferences 未改键名）

## 已知遗留

- 弹卡在**旋转**时会关闭（系统 dismiss + Activity 重建，与 1.1 行为一致）。
- 「跟随壁纸」下**对比度档不生效**（系统动态取色不提供对比度入参）。
- 旋转 / 折叠屏 / 分屏下的弹卡形态跟随**尚未在真机验证**（缺折叠屏与分屏环境）。
- 保活与补偿链路的**真机回归未做**（灭屏触发 / 伪关闭恢复 / 权限撤销告警 / 多服务并发 / 通知未授权）。
