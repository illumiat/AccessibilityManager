# 无障碍管理器 1.2.2（修复版）

> 承接 1.2.1 的小修复版。只改了一处**用户可见的显示错误**，并补做了三项此前未完成的真机验证。
> 未引入新功能，界面与行为与 1.2.1 一致。

## 修复

- **设置页底部的版本号显示错误**：此前固定显示「无障碍管理器 v9.0」，而安装包实际是 1.2.x ——
  这个数字与包内版本号长期不符（真机确认：1.2.1 的包显示 v9.0）。
  现改为**从安装包自身的版本号读取**，以后每次发版都会自动显示正确版本，不会再出现这种脱节。

## 兼容

- 安装方式不变：release 构建 + debug keystore 签名，**可覆盖 1.2 / 1.2.1 安装，无需卸载**。
- 最低系统、授权方式、数据与配置沿用（与 1.2 一致）。

## 本轮补做的真机验证

- **动态取色的运行期切换**：改为单 Activity 形式后，该 API 的字节码里**不再注册任何进程级回调**
  （`applyToActivityIfAvailable` 的字节码中 `registerActivityLifecycleCallbacks` 出现 0 次，
  而旧的 `applyToActivitiesIfAvailable` 出现 1 次），机制上已无状态；主题变更必走 Activity 重建，
  故「切回命名主题却被壁纸配色盖住」这条路径在结构上不可能再出现。
- **列表三行文案未溢出**：实测渲染 2 行（未触及 3 行上限）。
- **灭屏 / 亮屏**：无障碍服务表前后一致（7 条）、守护进程存活。
- **权限撤销**：撤销「安全设置写入权限」后，设置页如实显示「未授予」；恢复后回到「已授予」；
  全程无崩溃、无障碍服务表未受影响。

## 已知遗留 / 仍未验证

- **伪关闭恢复、多服务并发**：未做真机回归。
- **动态取色的视觉效果**未做逐像素比对（只证明了机制无状态）。
- **详情卡卡片外壳**只做了参数级与结构级核验（两处卡片外观参数逐项一致、正文左边界一致、
  开关为 M3 默认尺寸且与标题垂直居中），**未做像素级比对**。
- 动态取色「跟随壁纸」下**对比度档不生效**：这是已裁决的取舍（跟随系统动态取色不提供对比度入参），
  非待修缺陷。
- lint 在当前工具链（AGP 8.7.3 + compose）下仍不可用，不作为验收依据。
